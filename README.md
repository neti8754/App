# StockCheck

אפליקציית Android לניהול בדיקת מלאי שהופכת פריטים חסרים לרשימת קניות מרכזית.

## יכולות
- רשימות קבועות וניתנות לעריכה.
- בדיקת כל פריט: יש / חסר.
- איחוד אוטומטי של פריטים חסרים, גם כשהם מגיעים מכמה רשימות.
- הצגת מקורות הרשימות ליד כל פריט קנייה.
- סימון פריט כנקנה, מחיקה והוספה ידנית.
- חיפוש רשימות ומשימות.
- סינון משימות: פתוחות / הכול / הושלמו.
- ערכת נושא מערכת/בהיר/כהה ובחירת צבע מודגש.
- שמירה מקומית באמצעות DataStore.
- ממשק RTL בעברית.

## Build
GitHub Actions מריץ tests ו-build ל-debug APK ושומר את ה-APK כ-artifact בשם StockCheck-debug.
